Aide

Toucher un titre pour l'ouvrir ou le fermer.

Suggérer un lieu
1. Trouver
Taper le nom dans la boîte Chercher un lieu, puis choisir « Chercher … sur la carte ». Vérifier que l'épingle est au bon endroit.
2. Copier
Cliquer Copier pour le Google Sheet, puis coller dans une note sur votre téléphone ou ordinateur (une ligne par lieu).
3. Ajouter
Sous chaque lieu, écrire en quelques mots pourquoi il vous plaît, et coller les liens à partager (vidéo, blogue, photos).
4. Envoyer
Quand vous en avez quelques-uns, envoyer la note à David. Il les ajoute à la carte.
Pas trouvé ?
Si la page ne trouve pas le lieu, l'ouvrir dans Google Maps, toucher Partager, puis Copier le lien, et coller ce lien dans la note.
Modifier une fiche (photos, liens, textes)
1. Ouvrir
Toucher Modifier (le crayon) en haut de la fiche.
2. Code
La première fois, entrer le code d'accès (le demander à David). La page s'en souvient ensuite sur cet appareil.
3. Coller
Photos : une adresse d'image par ligne (clic droit sur l'image, « Copier l'adresse de l'image »). Pour en savoir plus : une courte description puis le lien, un par ligne. Trucs et astuces : un conseil par ligne. Icônes : la barre d'icônes en haut de l'écran les insère là où se trouve le curseur ; une ligne qui commence par « Distance : », « Durée : », « Difficulté : » ou « Pourquoi : » reçoit son icône toute seule. Dans les autres textes : une ligne vide = nouveau paragraphe, « - » au début d'une ligne = puce, **texte** entre deux paires d'étoiles = gras.
4. Enregistrer
La fiche change tout de suite sur votre écran. Les autres la verront d'ici environ 5 minutes.
Lire une fiche
Nom souligné
Toucher le nom pour voir le lieu sur la carte. Toucher un point sur la carte met sa fiche en évidence.
Détails
Chaque fiche est fermée au départ. Détails l'ouvre. Son en-tête (nom, Modifier, Fermer, onglets) reste en haut pendant qu'on la lit.
Photos
En ouvrant une fiche, les photos et vidéos choisies pour ce lieu défilent avec les flèches (ou en glissant le doigt sur un téléphone).
Boutons
YouTube cherche le nom du lieu. Google Maps ouvre l'endroit exact. Le bouton Photos (recherche Google) n'apparaît que si le lieu n'a pas encore ses propres photos.
Couleur
Celle du port d'attache. Gris = Hors trajet : à plus de 40 km de tous les ports d'attache.
Numéro (ex. 3.4)
Port d'attache n° 3, 4e lieu. A = Hors trajet.
Distance
À vol d'oiseau, depuis le port d'attache le plus proche.
Statut
À explorer (point creux) : trouvé, pas encore regardé de près.
Bon candidat (point plein) : un bon arrêt possible.
Confirmé (gros point cerclé) : on y va.
Mis de côté (point pâle, caché par défaut) : on n'y va pas.
Les boutons en haut cachent ou montrent chaque groupe.
Région
En ouvrant un port d'attache, on voit le résumé et les astuces de sa région.
Trajet
Trait plein : train · pointillé : avion · cercle avec auto : en auto.
Les onglets de la fiche
Onglets
Un onglet par section : Aperçu, Y aller, À faire, Astuces, Liens, Avis. Tout voir montre tout d'un coup, pour lire la fiche au complet.
Contenu
Aperçu (pourquoi y aller), Comment s'y rendre, Quoi faire et Trucs et astuces, tirés de récits de voyageurs. Un petit lien ↗ après une phrase mène au site dont elle parle (billets, horaires, refuge). Pour un lieu pas encore refait, l'onglet s'appelle Résumé ; sans texte à nous, la page montre Wikipédia.
Liens
Pour en savoir plus : les meilleurs liens pour approfondir, avec ce qu'on y trouve. Liens du groupe : vidéos, blogues ou photos partagés par le groupe.
Icônes
vidéo · image · site Web
Avis
Les votes de chacun. À discuter = nos votes diffèrent. Un onglet vide n'apparaît pas.
Pour le Google Sheet (David)
Principe
Tout vient du Google Sheet « Italie 2027 – Lieux ». Pour changer la page, on change le Google Sheet. Le mode d'emploi complet est dans l'onglet Mode d'emploi.
Fiche
Onglet Lieux : Aperçu, Comment s'y rendre, Quoi faire, Trucs et astuces (une phrase = un conseil), Pour en savoir plus (description puis lien, séparés par « ; »). Les anciennes colonnes Note, Astuces et Sources servent encore aux lieux pas encore refaits.
Photos
Colonne Photo : une ou plusieurs adresses, séparées par « ; ». Pour une image : clic droit sur l'image, « Copier l'adresse de l'image ». Une vidéo YouTube ou Vimeo joue dans le carrousel ; un lien Facebook, Instagram ou TikTok devient un bouton « Voir la vidéo ». Une page de galerie (pas une image) va plutôt dans Pour en savoir plus.
Liens du groupe
Onglet Liens : Lien, Description (texte affiché), Lieux (écrits exactement comme dans Lieux).
Votes
Onglet Votes : Lieu, Qui, Vote, Commentaire. Le dernier vote de chacun compte.
Région
Onglet Régions : Région, Aperçu (ou Résumé), Trucs et astuces (ou Astuces), Pour en savoir plus (ou Sources). Le nom doit être exactement le même que le port d'attache dans Trajet.
Ajouter un lieu
« Copier pour le Google Sheet » copie une ligne complète : coller dans la colonne Lieu d'une nouvelle ligne, et le nom, les coordonnées, le statut, le type et la région se placent tout seuls.
Sans coordonnées
Les lieux sans coordonnées sont listés dans l'encadré jaune. Trouver les coordonnées les cherche autour de leur région, puis donne un bouton Copier par bloc de lignes qui se suivent, avec la case exacte où coller (ex. A8). Pour un lieu pas trouvé : dans Google Maps, clic droit sur le lieu lui-même (le lac, le sommet, l'église, pas le départ du sentier), cliquer sur les coordonnées pour les copier, les coller dans sa case Coordonnées. Le nombre de décimales n'a pas d'importance.
Mise à jour
La page lit le Google Sheet chaque fois qu'on l'ouvre. Après une modification, attendre environ 5 minutes, puis cliquer sur Recharger.
